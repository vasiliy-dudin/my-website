# Portfolio Decisions

Verdicts and basis labels are defined in `decisions_rules.md`.
Structure, tiers, scannability and honesty criteria live in
`quality_criteria.md` — rows below only set defaults where evidence or
cost decides.

## Structure and entry point

| Recommendation | Verdict | Basis |
|---|---|---|
| Homepage answers who / what / level without a click | Do | [reported] convergent HM accounts; see `quality_criteria.md` |
| Assume a skimming reader; no specific seconds figure exists | Do | [reported] short first pass is consistent; the "30–60 seconds" number is [none] |
| 2–3 featured case studies, lighter work in tier 2 | Do | [reported] convergence on 3–4; structure per `quality_criteria.md` |
| Lead case = clearest outcome and strongest own decisions | Do | see `quality_criteria.md` |
| First case study front-loads problem and outcome | Do | [reported] problem framing is read closely on first pass |
| Check the site on mobile | Do | [inference] some first passes happen on mobile; cheap |
| Case study survives a 10-minute spoken walkthrough | Do | [mechanic] the loop includes a live presentation |
| Video walkthroughs, motion intros, novel navigation | Ask first | [none] days of work on no evidence |

## Content of cases

| Recommendation | Verdict | Basis |
|---|---|---|
| Show negative metrics honestly with the four required elements | Do | see `quality_criteria.md` |
| Invented, unverifiable or retrofitted details (including AI use in projects where it wasn't used) | Don't | provenance rules in `quality_criteria.md`; indefensible in a live walkthrough |
| Show AI fluency through a tier 2 AI project, the site itself, or About — not by editing history | Do | [reported] absence of AI signals now reads as avoidance; honesty preserved |
| Visibly AI-patterned case study prose | Don't | sameness problem — see `market_context.md`; apply `writing_guidelines.md` where present |
| Concept work or fantasy redesigns as featured cases | Don't | [reported] rejected by HMs at senior level; tier 2 with honest framing is the place |
| UI screenshots in English | Do | see `quality_criteria.md` |

## Access and formats

| Recommendation | Verdict | Basis |
|---|---|---|
| Password on the whole portfolio | Don't | [reported] reviewers bounce rather than request access |
| NDA work: anonymise and redact in place rather than "can't show" slides | Do | [reported] named HM guidance; accepted practice |
| Live URL as the applying format; a walkthrough deck prepared when interviews start | Do | [reported] convention; deck effort deferred until needed |
